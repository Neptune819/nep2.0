# NEP 番剧推荐系统 — 项目介绍

## 一、项目概述

NEP（Anime Recommendation Engine）是一个基于心理画像和多因子算法的个性化番剧推荐系统。系统收录了来自 AniList 和 Bangumi 的 **13,500+ 部精选番剧**，通过 15 个维度的复合评分算法，为每位用户生成个性化的推荐结果。

与传统"看了这个的人也看了"的协同过滤不同，NEP 从用户的**心理偏好**出发——你喜欢什么类型的故事、你的认知风格、情感需求、世界观认同——来预测你可能喜欢的番剧。

---

## 二、核心功能

### 2.1 六种推荐模式

| 模式 | 入口 | 说明 |
|------|------|------|
| **按番剧** | 首页 Tab | 选一部你喜欢的番，推荐相似作品。支持续集分离显示 |
| **按看番历史** | 首页 Tab | 导入你的观看记录，基于全部历史的复合匹配推荐 |
| **按标签** | 首页 Tab | 勾选你喜欢的标签（419 个可选），匹配推荐 |
| **按声优** | 首页 Tab | 搜索声优名（支持中文别名），查看其配音作品 |
| **本季热门** | 首页 Tab | 当季热门 + 高分番剧，按综合质量排序 |
| **每日推荐** | 首页 Tab | 基于心理画像，每天推荐 100 部，一周不重复 |

### 2.2 推荐风格

用户可在左上角全局切换三种推荐风格：

| 风格 | 浮动幅度 | 偏好 |
|------|----------|------|
| 🔭 **探索型** | ±15% | 偏向冷门佳作（排名 1000-8000），降低低分番惩罚 |
| ⚖️ **标准型** | ±5% | 均衡推荐，兼顾热门与冷门 |
| 🎯 **保守型** | ±2% | 偏向热门经典（排名 1-500），高匹配度 |

### 2.3 心理画像问答

系统提供两种问卷模式：

- **简易版**（20 题，2-3 分钟）：快速生成心理画像
- **复杂版**（60 题，8-10 分钟）：深度分析心理偏好

问卷题目全部围绕动漫偏好设计，通过用户的选择推断其：
- 大五人格（开放性、尽责性、外向性、宜人性、神经质）
- 原型偏好（英雄、智者、探索者、叛逆者等）
- 防御机制（幻想、升华、幽默等）
- 叙事偏好（线性、多线、意识流等）
- 世界观认同（现实、奇幻、科幻、末日等）

测试结果自动融入推荐算法，影响「按看番历史」和「每日推荐」的输出。

### 2.4 调参系统

15 个推荐因子全部可调，每个因子提供三档按钮：

| 档位 | 效果 | 影响范围 |
|------|------|----------|
| 🟢 低档 | 降低该因子影响 | ×0.7 |
| 🟡 中档 | 默认（不变） | ×1.0 |
| 🔴 高档 | 增强该因子影响 | ×1.3 ~ ×3.0 |

调参支持**复合运算**——当多个相关因子同时调高档位时，会产生协同放大效果：
- 制作公司 + 标签同时调高 → 标签效果额外 ×1.3
- 历史 + 标签同时调高 → 共振加成 ×1.2
- 评分 + 综合质量同时调高 → 质量共振 ×1.15
- 厂牌三因子（制作公司/声优/Staff）≥2 个同时调高 → 联动 ×1.2~1.4

### 2.5 待看列表 & 收藏列表

系统提供两个个人列表：

- **⭐ 收藏列表**：你收藏过的番剧，可打分（1-10 分），评分影响推荐结果
- **📌 待看列表**：标记想看但还没看的番剧，可一键转为收藏

在任何页面点击番剧卡片打开详情弹窗，底部即可操作"加入待看"或"收藏"。

### 2.6 其他功能

| 功能 | 说明 |
|------|------|
| **批量导入** | 粘贴文本或上传文件（DOCX/PDF/TXT），自动识别番剧名 |
| **番剧详情弹窗** | 点击任意卡片查看完整信息：简介、标签、声优、Staff、续集、相似推荐 |
| **BGM 音乐播放器** | 上传本地音乐，播放控制、音量调节、自动下一首 |
| **背景图自定义** | 上传本地图片作为背景，支持多张切换 |
| **樱花飘落动画** | 默认开启的轻量粒子动画 |

## 五、快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动
python app.py
# 或双击 start.bat（Windows）

# 3. 打开浏览器
# http://127.0.0.1:5000
```
