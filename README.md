# 🎬 番剧推荐网站

基于心理画像的个性化番剧推荐系统，数据源：AniList + Bangumi。

## ✨ 主要功能

### 🧠 心理画像推荐（v2.0 新增）
- 24维度心理画像：大五人格、MBTI、九型人格、原型、防御机制、需求等
- 基于用户选择的番剧自动推断心理偏好
- 心理匹配因子融入推荐算法，推荐更符合内心需求的作品

### 🎯 三种推荐模式
| 模式 | 说明 |
|---|---|
| 按番剧 | 选择一部喜欢的番剧，推荐相似作品 |
| 按历史 | 导入你的观看列表，基于偏好推荐 |
| 按标签 | 选择喜欢的标签类型，匹配推荐 |

### 🔍 发现型推荐（v2.0 新增）
- **被低估佳作**：评分高但人气相对冷门的作品（人气排名500-3000）
- **经典老番**：2010年之前但质量极高的经典作品
- **口味盲区**：基于心理画像预测你可能感兴趣但没接触过的类型

### 📝 心理画像问答（v2.0 新增）
- 简易版：20道精选题目，2-3分钟快速生成心理画像
- 复杂版：60道深度题目，8-10分钟全面了解心理偏好
- 答题结果自动融入推荐算法

### 📋 批量导入
- 支持文本粘贴（每行一个番剧名）
- 支持文件上传（DOCX/PDF/TXT）
- 自动识别番剧名称（支持别名、括号、序号等格式）
- 解析后自动添加到列表

### 🎙️ 声优搜索
- 搜索声优名称（支持中文别名）
- 查看该声优配音的所有番剧

### 🔥 本季热门
- 显示当季热门番剧
- 按综合质量排序

### ⚙️ 权重调优
- 15个因子可自由调整
- 实时影响推荐结果

### 🎵 BGM音乐播放器
- 支持上传MP3/WAV/OGG/M4A
- 播放控制、音量调节
- 自动播放下一首

### 📚 我的番剧列表
- 独立页面管理
- 支持搜索、筛选、排序
- 支持导出/导入JSON

## 🚀 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动服务
```bash
# Windows 双击 start.bat
# 或命令行
python app.py
```

### 3. 访问页面
- 主页：http://127.0.0.1:5000
- 心理画像问答：http://127.0.0.1:5000/quiz
- 我的列表：http://127.0.0.1:5000/mylist

## 📁 项目结构

```
├── app.py                  # Flask 入口（30+ API）
├── recommender.py          # 推荐器（15因子 + 心理匹配 + 发现型推荐）
├── multi_factor.py         # 15因子打分模块（含心理匹配因子）
├── psych_profile.py        # 心理画像系统（24维度 + 150标签映射）
├── discovery_engine.py     # 发现型推荐引擎（被低估/经典/盲区）
├── quiz_system.py          # 问答系统（20题/60题 → 心理画像）
├── data_loader.py          # 数据加载 + 搜索
├── start.bat               # 一键启动脚本
├── requirements.txt        # 依赖列表
│
├── data/
│   ├── anime_cache.json    # 番剧数据缓存
│   ├── tag_translations.json
│   ├── va_translations.json
│   └── bgm/                # BGM音乐文件夹
│
├── templates/
│   ├── index.html          # 主页
│   ├── quiz.html           # 心理画像问答
│   └── mylist.html         # 我的列表
│
└── static/
    ├── style.css           # 样式
    ├── script.js           # 主逻辑
    ├── detail.js           # 详情弹窗
    └── ...
```

## 🎵 添加BGM

将MP3文件放入 `static/bgm/` 文件夹，刷新网页即可在播放器中看到。

## 📊 数据规模

- 番剧总数：12,223 部（已过滤国漫和R18内容）
- 声优数据：5,773 位
- 标签数量：419 个
- 心理维度映射：150 个标签

## 🔧 技术栈

- 后端：Flask + Python
- 前端：HTML/CSS/JavaScript
- 算法：scikit-learn（TF-IDF + NearestNeighbors）+ 心理画像匹配 + 复合评分算法
- 数据：AniList GraphQL API
